## FAQ

**How do I update the portfolio content?**  
Edit the HTML files and replace the existing text and visuals with your own design work.

**Where are the settings stored?**  
Most changes will be made directly in the project files, especially the HTML and asset references.

**Can I preview it locally?**  
Yes. Open the site in a browser or use a local server if you prefer a development preview.

**How do I keep it current?**  
Refresh the portfolio with new projects, updated descriptions, and newer screenshots or mockups as your work changes.

**What should I do if something looks off in the browser?**  
Check file paths, image sizes, and HTML structure, then test again in another browser to compare rendering.
